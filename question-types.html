🧾 The CSV contract (14 columns)

Row 1 is the header; data starts at row 2. Columns 1–7 are the classic base format that works with older banks. Columns 8–14 are optional extensions — leave them blank for simple MCQ. Wrap any cell containing commas in double quotes.

ColumnNameUsed byWhat goes in it
Col1QuestionYesThe question text / instructions. Use ___ for cloze blanks.
Col2–5Options A–DMost typesChoices for mcq/mrq/tf; the right-side pool or categories for matching/categorization.
Col6CorrectAnswerYes (type-dependent)Key letter, exact text, number, min-max range, or comma letters for mrq.
Col7ExplanationNoShown to the student in review mode after submission.
Col8TypeYesOne of the 20 type names above — see the type cards.
Col9Tolerancenumeric± tolerance for numeric answers.
Col10Unitnumeric / codeUnit label (kg, cm) or programming language for code.
Col11Acceptshort / image_mcq / matrix / code / essayExtra accepted answers (pipe-separated), image path, matrix choices, keywords.
Col12MRQ_AONmrq1 (default) = all-or-nothing, 0 = partial credit.
Col13PairsmatchingJSON pair array [{"l":"…","r":"…"}] plus optional DISTRACTOR rows.
Col14ItemsJSON typesStructured payload: pairs, rows, parts, regions, passage, tests…

Core — Everyday fundamentals

The six types that cover most classroom tests — start here.

mcq Multiple Choice

One best answer out of up to four options. The workhorse of every CBT.

Columns
Col1 question · Col2–Col5 options A–D · Col6 key letter (A/B/C/D)
Scoring
Exact key match → full mark. No partial credit.
CSV row example
"What is 7 × 8?","49","54","56","63","C","","mcq"

Student sees: Option buttons A–D; one tap selects, tapping another switches.

tf True / False

Binary statement judgement — fast to write, fast to answer.

Columns
Col1 statement · Col2 = True text · Col3 = False text · Col6 = A (True) or B (False)
Scoring
Exact match on A/B → full mark.
CSV row example
"The Niger River flows into the Atlantic Ocean.","True","False","","","A","","tf"

Student sees: Two large option cards (True / False).

mrq Multiple Response

Select ALL correct answers — great for "which of the following" items.

Columns
Col6 = sorted letters e.g. A,C · Col12 MRQ_AON controls marking
Scoring
All-or-nothing (MRQ_AON=1, default) or partial credit per correct/incorrect selection (MRQ_AON=0).
CSV row example
"Select prime numbers","2","9","11","15","A,C","","mrq","","","","","0","",""

Student sees: Checkbox-style multi-select; tap toggles each option.

short Short Answer

Type a word or phrase — spelling-aware but case-insensitive.

Columns
Col6 primary answer · Col11 extra accepted answers separated by |
Scoring
Case-insensitive exact match against the primary + accepted list.
CSV row example
"Chemical symbol for gold?","","","","","Au","","short","","","Au|gold|AU"

Student sees: Single-line text input.

numeric Numeric

Precise number entry with tolerance — built for maths and science.

Columns
Col6 value · Col9 tolerance (±) · Col10 unit label
Scoring
|student − key| ≤ tolerance → full mark.
CSV row example
"Mass of 1 litre of water (kg)?","","","","","1","","numeric","0.05","kg"

Student sees: Number pad input with unit hint beside it.

range Range / Estimation

Any value inside an accepted interval earns the mark — ideal for estimation.

Columns
Col6 = min-max (e.g. 15-25) · or Col14 = {"min":15,"max":25}
Scoring
Value within [min, max] inclusive → full mark.
CSV row example
"Estimate Nigeria's population (millions)","","","","","180-220","","range"

Student sees: Number input labelled with the accepted range.

Pairing & Ordering — Structure & relationships

Match, order, sort and multi-part formats powered by the Items (Col14) JSON column.

matching Matching

Match left items to right options; extra DISTRACTOR rows make it harder.

Columns
Col1 instructions · Col2–Col5 = right-side options · Col13 = [{"l":"…","r":"…"}] pairs (+ optional DISTRACTOR rows)
Scoring
Fraction per correctly matched pair.
CSV row example
"Match country to capital","Abuja","Accra","Nairobi","","","B","","matching","","","","","[{""l"":""Nigeria"",""r"":""Abuja""},{""l"":""Kenya"",""r"":""Nairobi""},{""l"":""Ghana"",""r"":""Accra""}]"

Student sees: Each left item has a dropdown of the right options.

ordering Ordering / Sequencing

Arrange steps or events into the correct sequence.

Columns
Col14 = ["first","second",…] in correct order
Scoring
Fraction per item in the correct position.
CSV row example
"Order these from smallest to largest","Dust","Sand","Gravel","","","","ordering","","","","","","[""Dust"",""Sand"",""Gravel""]"

Student sees: Dropdown picks 1st, 2nd, 3rd… for each row.

cloze Cloze / Fill-in-the-Blanks

Multiple blanks inside one passage, each blank typed by the student.

Columns
Col1 text with ___ markers · Col14 = ["ans1","ans2",…] (one per blank)
Scoring
Fraction per correctly filled blank (case-insensitive).
CSV row example
"The ___ rises in the east and sets in the ___.","","","","","","","cloze","","","","","","[""sun"",""west""]"

Student sees: Inline text boxes where the blanks appear.

categorization Categorization

Assign each item to its category — classic sorting exercise.

Columns
Col2–Col5 categories · Col14 = [{"item":"…","category":"…"}]
Scoring
Fraction per item placed in the right category.
CSV row example
"Sort into metals / non-metals","Metal","Non-metal","","","","","categorization","","","","","","[{""item"":""Sodium"",""category"":""Metal""},{""item"":""Chlorine"",""category"":""Non-metal""}]"

Student sees: Each item has a dropdown of the categories.

multi_numeric Multi-Part Numeric

Several labelled numeric answers in one question (labs, multi-step maths).

Columns
Col14 = [{"label":"a)","answer":3,"tolerance":0},…]
Scoring
Fraction per part within its own tolerance.
CSV row example
"From the graph: read x and y","","","","","","","multi_numeric","","","","","","[{""label"":""x (cm)"",""answer"":3,""tolerance"":0.2},{""label"":""y (cm)"",""answer"":5,""tolerance"":0.2}]"

Student sees: One number input per labelled part.

matrix Matrix / Grid

Rows share the same set of choices (e.g. True/False per statement).

Columns
Col11 = choices like True|False · Col14 = [{"row":"…","answer":"True"},…]
Scoring
Fraction per correctly answered row.
CSV row example
"Decide each statement","Earth orbits the Sun","Light is sound","","","","","matrix","","","True|False","","","[{""row"":""Earth orbits the Sun"",""answer"":""True""},{""row"":""Light is sound"",""answer"":""False""}]"

Student sees: Grid of rows, each with the same choice buttons.

Higher-Order — Bloom's upper levels

Analysis, evaluation and extended writing — including AI-free auto-marked essays and code.

assertion_reason Assertion–Reason

WAEC/JAMB-style A–E logic combining an assertion and a reason.

Columns
Col6 = A/B/C/D/E · Col14 = {"assertion":"…","reason":"…"}
Scoring
Exact letter match → full mark.
CSV row example
"A: Copper conducts. R: It is a metal.","A both true, R explains A","B both true, R does not explain A","C A true, R false","D A false, R true","E both false","A","assertion_reason","","","","","","{""assertion"":""Copper conducts electricity."",""reason"":""Copper is a metal with free electrons.""}"

Student sees: Statement pair shown together, then A–E option cards.

case_study Case Study / Comprehension

A shared passage or dataset followed by one or more MCQs on it.

Columns
Col14 = {"passage":"…"} · normal MCQ columns for options/key
Scoring
Exact key match → full mark. Passage auto-pins above its questions.
CSV row example
"According to the passage, the main cause is…","Drought","Flood","War","Famine","A","","case_study","","","","","","{""passage"":""The Sahel region has faced recurring drought since the 1970s…""}"

Student sees: Sticky passage pane above the question cards.

image_mcq Image / Diagram MCQ

MCQ built around a diagram, chart or photo.

Columns
Col11 or Col14 = image URL / data URI · normal MCQ columns
Scoring
Exact key match → full mark.
CSV row example
"Which angle is obtuse in the figure?","Angle P","Angle Q","Angle R","Angle S","C","","image_mcq","","","img/angles.png"

Student sees: Image renders above the option cards; broken links degrade to a text warning.

essay Essay / Long Response

Extended written answers, auto-checked by transparent word/keyword rules.

Columns
Col6 = model points · Col11 = keywords · Col14 = {"min_words":120,"keywords":["…"]}
Scoring
Min-word gate + keyword coverage score; flagged for teacher review on high-stakes use.
CSV row example
"Explain photosynthesis in your own words","","","","","light energy, chlorophyll, glucose","at least 120 words","essay","","","chlorophyll|glucose","","","{""min_words"":120}"

Student sees: Large textarea with live word counter.

code Code / SQL / Algorithm

Write code in a monospace editor; keyword and rule-based checks.

Columns
Col10 = language · Col11 = keywords separated by | · Col14 = optional tests JSON
Scoring
Keyword coverage + optional test rules; flagged for teacher review.
CSV row example
"Write a SQL SELECT with WHERE","SELECT * FROM students WHERE age > 10","","","","SELECT, FROM, WHERE","must contain a WHERE clause","code","","sql","SELECT|FROM|WHERE"

Student sees: Monospace editor with language label.

hot_text Hot Text (select words)

Tap the correct words or phrases directly inside a sentence.

Columns
Col14 = [{"t":"word","correct":true},…] chunks
Scoring
Fraction per correct tap, minus wrong taps, floored at 0.
CSV row example
"Tap the two verbs","The boy quickly ran home","","","","","","hot_text","","","","","","[{""t"":""The "",""correct"":false},{""t"":""boy "",""correct"":false},{""t"":""quickly "",""correct"":false},{""t"":""ran "",""correct"":true},{""t"":""home"",""correct"":false}]"

Student sees: Words render as tappable chips inside the sentence.

Visual & Evidence — New in this release

Tap-an-image and two-part evidence questions, matching the School Connect / GOSA Portal engine.

hotspot Hotspot (tap the image)

Tap the correct region of a diagram, map or chart.

Columns
Col6 = correct region label · Col14 = {"image":"url","regions":[{"label":"A","x":20,"y":35},…]} (x/y = % position)
Scoring
Correct region label → full mark.
CSV row example
"Tap the equator on the map","","","","","Equator","","hotspot","","","","","","{""image"":""img/world-map.png"",""regions"":[{""label"":""Equator"",""x"":50,""y"":48},{""label"":""Tropic of Cancer"",""x"":50,""y"":38},{""label"":""Tropic of Capricorn"",""x"":50,""y"":60}]}"

Student sees: Numbered dots appear on the image; tapping one records that label. If the image cannot load, labelled buttons appear instead so the question is still answerable.

evidence_mcq Evidence-Based MCQ (2-part)

SAT/WAEC-style linked pair: choose the answer, then the sentence that best proves it.

Columns
Col14 = {"part1":{"question":"…","options":[…],"answer":"…"},"part2":{…}} (answer = exact option text)
Scoring
Both parts right → full mark; one part right → half mark.
CSV row example
"(Part A) What is the theme? … (Part B) Which line proves it?","","","","","","","evidence_mcq","","","","","","{""part1"":{""question"":""What is the main theme of the passage?"",""options"":[""Survival"",""Betrayal"",""Love"",""Justice""],""answer"":""Survival""},""part2"":{""question"":""Which line best supports your answer?"",""options"":[""He shared his last water"",""The sun was hot"",""She sang softly"",""They walked far""],""answer"":""He shared his last water""}}"

Student sees: Two stacked option-card groups (Part A then Part B), each independent until submitted.

⌨️ JSON escaping rule (Col13 / Col14)

Whenever a cell contains JSON, wrap the whole CSV cell in double quotes and write every inner double-quote as two double-quotes:

"[{""item"":""Sodium"",""category"":""Metal""}]"

The AI Prompts Studio and PROMPT_TEMPLATE.md both generate correctly-escaped CSV automatically — and every example row on this page is copy-paste ready.

🔀 Cross-platform compatibility

📥 Import from School Connect / GOSA Portal
CSVs exported from either platform import here without editing — any column order, their headers (question,type,a,b,c,d,answer,explanation,mark…) and their type names (true_false, multi_select, fill_blank, image_hotspot, evidence…) are auto-detected and mapped.
📤 Export back out
Any bank built here exports as a School Connect-compatible CSV from Assessments → Bank → Export School Connect CSV, so questions flow freely between all three platforms.
🤖 Free AI-assisted authoring
No paid AI APIs anywhere. Copy a prompt from the studio, paste into any free AI chat, get a ready-to-upload CSV — then validate and load it. Essays and code are marked by transparent keyword / minimum-word / rule checks with teacher review recommended for high-stakes grading.
