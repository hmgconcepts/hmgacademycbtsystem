🧭 How monitoring, renewal & bypass work

  1. Monitor: "Check all now" polls every client's real license row over their public REST endpoint and shows the truth: 🟢 active/lifetime · 🟡 warning (days left) · 🟠 grace · 🔴 expired (days over) · ⏸ suspended · ❌ unreachable (usually a paused Supabase project — restore it, then re-check).
  2. Renew (from inside their platform): the License console and Admin sign-in stay reachable even while a client's portal is locked — quick-extend +30/+90/+365 days re-activates instantly.
  3. Bypass / override (from your side): each client card generates the exact license-registry JSON — extend the expiry, flip status to active, or convert to lifetime. Paste it into the registry file you host (Settings → license registry URL on their platform, or baked by the Generator). The registry always beats local values.
  4. Never goes dark: even expired platforms keep heartbeating (site-visit pings + the scheduled GitHub workflow), so Supabase never pauses them for inactivity — renewal is always one action away, zero rebuild, zero data loss.
