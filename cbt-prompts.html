The studio above builds a prompt for you; this library hands you the finished classics in full. Level 1 · 🟢 Simple — "Quick Paper" (20 questions · mcq + true_false · any subject)

For class quizzes, end-of-topic checks and homework reviews. Fills in 30 seconds, works in every AI chat, imports first time.

You are an expert teacher writing a quick class quiz.

TASK: Write 20 questions on {{SUBJECT and TOPIC, e.g. "JSS 2 Basic Science — The Human Digestive System"}} at {{LEVEL, e.g. "JSS 2 / Year 8"}} level.
Use 15 multiple-choice (mcq) and 5 true/false (true_false) questions. Difficulty: 12 easy, 6 medium, 2 hard.

OUTPUT: ONE CSV code block. First line exactly:
Question,A,B,C,D,CorrectAnswer,Explanation,Type,Tolerance,Unit,Accept,MRQ_AON,Pairs,Items,Difficulty,Tags,Section

RULES
1. 17 columns per row, in that exact order. Wrap every cell in double quotes; write inner double-quotes as two ("").
2. mcq: options in columns A-D (4 options), CorrectAnswer = one letter (A/B/C/D). One clearly correct answer.
3. true_false: column A = "True", column B = "False", C and D empty, CorrectAnswer = "True" or "False".
4. Explanation (column 7) is MANDATORY for every question, 2-4 sentences:
   state the correct answer in words, give the reason, and say why the most tempting wrong option is wrong.
5. No "all of the above" / "none of the above" options. No trick questions.
6. Difficulty column: easy / medium / hard. Tags column: topic and subtopic, comma-separated.
7. Output ONLY the CSV block — no commentary before or after.

Level 2 · 🟡 Intermediate — "Mixed Skills Paper" (30 questions · 7 types incl. numeric, matching, ordering)

For term tests that should feel like a real exam: typed answers, tolerance-based numerics, and drag-to-match interactions.

You are an expert examiner setting a term test for {{SUBJECT, e.g. "SS 1 Mathematics"}} at {{LEVEL/BOARD, e.g. "WAEC SS 1"}} level.

TASK: Write exactly 30 questions on {{TOPIC(S), e.g. "Algebraic processes and mensuration"}} with this mix:
12 mcq, 4 true_false, 5 short_answer, 4 numeric, 3 matching, 2 ordering.
Difficulty spread: 12 easy, 12 medium, 6 hard.

OUTPUT: ONE CSV code block with this exact header:
Question,A,B,C,D,CorrectAnswer,Explanation,Type,Tolerance,Unit,Accept,MRQ_AON,Pairs,Items,Difficulty,Tags,Section

RULES
1. 17 columns per row in that order. Every cell double-quoted; inner double-quotes doubled (""). No line breaks inside a cell.
2. mcq: 4 options (A-D), CorrectAnswer = one letter. true_false: A="True", B="False", CorrectAnswer="True"/"False".
3. short_answer: the exact answer in CorrectAnswer; accepted alternative spellings in Accept, pipe-separated (e.g. "photosynthesis|photosyntheses").
   Keep required answers to 1-3 words. The question text must end with a blank indicator like ___ if a word is to be typed.
4. numeric: CorrectAnswer = the number; Tolerance = allowed error (e.g. 0.05); Unit = the unit label (e.g. "cm"). Questions must have one definite numeric answer.
5. matching: CorrectAnswer empty. Pairs (column 13) = one-line JSON array like [{"l":"Nigeria","r":"Abuja"},{"l":"Ghana","r":"Accra"}]
   with 4-6 pairs. Add 1 decoy as {"l":"DISTRACTOR","r":"Cairo"}.
6. ordering: CorrectAnswer empty. Items (column 14) = one-line JSON array of the items in their CORRECT order, e.g. ["evaporation","condensation","precipitation"].
7. Explanation (column 7) MANDATORY, 3-5 sentences: correct answer in words → the working or rule → why the classic wrong answer fails → one takeaway rule.
8. No "all/none of the above". Real names, real values, real contexts. Difficulty and Tags columns filled on every row.
9. Output ONLY the CSV block.

Level 3 · 🟠 Advanced — "Full Interactive Paper" (40 questions · every interactive type + cloze, categorization, multi-part numeric)

For premium mock exams: cloze passages, categorization grids, multi-part numerics and assertion/reason — all with JSON keys.

You are a chief examiner building a full-scale mock examination for {{SUBJECT, e.g. "SS 3 Chemistry"}} at {{BOARD, e.g. "WAEC SSCE"}} standard.

TASK: Write exactly 40 questions on {{SYLLABUS AREA}} with this mix:
14 mcq, 4 multi_select, 3 true_false, 5 short_answer, 5 numeric, 3 matching, 3 ordering, 2 cloze (fill-in-the-blank), 1 categorization, plus optionally 1 assertion_reason or multi-part numeric.
Difficulty: 16 easy, 16 medium, 8 hard.

OUTPUT: ONE CSV code block with this exact header:
Question,A,B,C,D,CorrectAnswer,Explanation,Type,Tolerance,Unit,Accept,MRQ_AON,Pairs,Items,Difficulty,Tags,Section

RULES
1. 17 columns, exact order, every cell double-quoted, inner quotes doubled, no raw newlines inside cells.
2. multi_select: 2-3 options are correct; CorrectAnswer = comma letters (e.g. "A,C"); MRQ_AON column = "false" for partial credit (or "true" if you want all-or-nothing).
3. cloze: the Question contains one ___ per blank; Items (column 14) = one-line JSON array with one answer per blank in order, e.g. ["solid","liquid","gas"].
4. categorization: Pairs (column 13) = one-line JSON array like [{"l":"HCl","r":"Acid"},{"l":"NaOH","r":"Base"}] — every left item must have a right category.
5. assertion_reason / multi-part numeric (optional): Items (column 14) = one-line JSON per this platform's spec:
   assertion_reason: {"assertion":"the assertion text","reason":"the reason text"} (or [{"a":…},{"r":…}]); multi_numeric: [{"label":"part a","ans":5,"unit":"cm"},{"label":"part b","ans":12,"unit":"cm"}] (answer/tolerance keys also accepted).
6. matching and ordering follow the JSON rules: Pairs = [{"l":"…","r":"…"},…] with optional {"l":"DISTRACTOR","r":"…"} decoys;
   Items = ["…","…",…] in correct order.
7. numeric: Tolerance + Unit always set. short_answer: Accept lists synonyms, pipe-separated.
8. Explanation MANDATORY, 4 moves, 40-70 words: VERDICT (restate the correct answer) → REASONING (the working/rule, numbered) → MISCONCEPTIONS (why each tempting wrong answer fails, or the one classic mistake) → TAKEAWAY (one transferable rule).
9. Senior-secondary level vocabulary only for the stated board. Real data and real contexts. No "all/none of the above".
10. Output ONLY the CSV block. Before answering, silently verify: 17 columns per row, exact count and mix, valid one-line JSON in columns 13/14 — then fix anything that fails.

Level 4 · 🔴 Enterprise v3 — "Exam Board Simulation" (section budgets · reference distribution · QA gates · full spec)

The master prompt for whole exam sittings: it plans sections, budgets types, targets documented misconceptions, and self-verifies before answering.

ROLE
You are a chief examiner and psychometrician with 20 years at a national examination board (WAEC/NECO/JAMB standard). You write curriculum-aligned, defensible, discrimination-tested items and full marking schemes.

MISSION
Produce a complete CSV question bank of exactly {{N, e.g. 60}} questions for:
  SUBJECT : {{subject, class, syllabus reference}}
  BOARD   : {{exam board + level, e.g. "JAMB UTME", "WAEC SSCE", "IGCSE Core"}}
  SECTIONS: {{section plan with per-section budgets, e.g. "Section A: 30 mcq (1 mark), Section B: 15 short/numeric (2 marks), Section C: 10 interactive (3 marks)"}}
  SOURCES : {{"based on the past questions / lesson notes / textbook chapters pasted below" or "original items only"}}
  STRESS  : target the documented misconceptions for this topic (from the sources, or well-established ones).

OUTPUT CONTRACT — one CSV code block, nothing else. Header exactly:
Question,A,B,C,D,CorrectAnswer,Explanation,Type,Tolerance,Unit,Accept,MRQ_AON,Pairs,Items,Difficulty,Tags,Section
Every cell double-quoted; inner double-quotes written as two (""); no line breaks inside any cell; JSON in columns 13/14 stays on one line.

TYPE-SPECIFIC KEYS (emit ONLY for types you actually use)
- mcq: one letter key; 4 plausible options of similar length; exactly one defensibly correct.
- multi_select: 2-3 correct; comma-letter key; MRQ_AON set ("false" = partial credit).
- true_false: A="True", B="False"; key = "True"/"False"; statements must be unambiguously one or the other.
- short_answer: 1-3 word answers; Accept = pipe-separated synonyms/alternative spellings; question ends with ___.
- numeric: single definite value; Tolerance (e.g. 0.05) and Unit mandatory; no compound calculations without stated intermediate results.
- matching: Pairs = [{"l":"…","r":"…"},…] 4-6 pairs + 1-2 {"l":"DISTRACTOR","r":"…"} decoys.
- ordering: Items = ["…","…"] in correct order; the platform scrambles them.
- cloze: one ___ per blank; Items = one answer per blank, in order.
- categorization: Pairs = [{"l":"item","r":"category"},…]; every item categorised.

EXPLANATION STANDARD — every row, 40-70 words, four moves:
1. VERDICT — restate the correct answer in full words.
2. REASONING — the working or rule, in logical order.
3. MISCONCEPTIONS — why each tempting distractor fails (name the misconception it embeds), or the one classic wrong method for typed types.
4. TAKEAWAY — one transferable rule for the candidate.

QUALITY GATES (silently self-check, then fix, before you answer)
G1. Exact count and per-section budgets; type mix as ordered.
G2. Every row has exactly 17 columns; JSON cells are valid one-line JSON.
G3. Every Explanation has all four moves; no row without an explanation.
G4. Difficulty spread within ±10% of 40% easy / 40% medium / 20% hard.
G5. No duplicate stems, no "all/none of the above", no opinion items, no content outside the stated syllabus.
G6. Maths in plain text (x^2, sqrt(x), 3/4); no LaTeX.
Then output the final CSV block only.

🎓 Strict UTME / JAMB Multi-Subject Sitting (4 subjects · one code · tabbed paper)

Builds the 4-in-1 paper this platform runs in tabbed multi-subject mode — the Section column splits it into subject tabs. Ask the AI to attach a downloadable .csv file; then import it in one step on the Multi-Subject Builder ⚡ Fast lane.

⬇️ Sample CSV 
You are a UTME preparation expert with 20 years of JAMB standard item-writing.

TASK: Write a complete 4-subject UTME-style paper. Subjects and counts:
  {{e.g. "English: 30, Mathematics: 25, Physics: 20, Chemistry: 20" — total exactly {{TOTAL}} questions}}.
All questions are 4-option mcq. One mark each.

OUTPUT: ONE CSV code block with this exact header:
Question,A,B,C,D,CorrectAnswer,Explanation,Type,Tolerance,Unit,Accept,MRQ_AON,Pairs,Items,Difficulty,Tags,Section

STRICT RULES
1. 17 columns per row. Every cell double-quoted; inner quotes doubled. No newlines inside cells.
2. Column 17 (Section) = the SUBJECT NAME on every row (e.g. "English"). The platform uses this column to build the subject tabs — never leave it empty and never invent other values.
3. JAMB/UTME standard: options of similar length; one defensibly correct answer; no "all/none of the above"; stems state exactly one problem; SS2-SS3 syllabus scope only; nothing outside the stated subject.
4. English sections to cover: comprehension-inference, lexis and structure, oral forms, register. Science subjects: spread across the syllabus proportionally.
5. Explanation (column 7) MANDATORY on every row, 3-5 sentences: correct answer in words → the rule/working → why the two most tempting wrong options fail.
6. Difficulty per subject: roughly 50% easy, 35% medium, 15% hard, recorded in column 15.
7. Output ONLY the CSV block.

✅ Strict MCQ-Only Paper (pure 4-option · imports into any CBT)

The most compatible format on earth — use it when the bank must load into other CBT software too.

You are an expert item writer. Write {{N}} four-option multiple-choice questions on {{SUBJECT/TOPIC}} at {{LEVEL}} level.

OUTPUT: ONE CSV code block with this exact header:
Question,A,B,C,D,CorrectAnswer,Explanation,Type,Tolerance,Unit,Accept,MRQ_AON,Pairs,Items,Difficulty,Tags,Section

STRICT RULES
1. Every row: Question text, exactly 4 option texts in A-D, one letter (A/B/C/D) in CorrectAnswer, a full explanation in column 7, "mcq" in column 8. Columns 9-14 empty. Difficulty, Tags, Section filled.
2. 17 columns per row, every cell double-quoted, inner quotes doubled, no line breaks in cells.
3. Exactly one correct answer per question; three distractors each embedding a DIFFERENT specific misconception; all four options similar in length and style.
4. Explanation: 3-5 sentences — correct answer in words, the rule or working, and why the most tempting distractor is wrong.
5. No "all of the above", "none of the above", no negative stems unless the skill itself requires them, no trick questions.
6. Difficulty: {{e.g. "40% easy, 40% medium, 20% hard"}}.
7. Output ONLY the CSV block — no preamble, no notes.
