🧭 Reading this page

  • Enrollment / exam trends answer "is the platform growing?" — flat bars after a deployment usually mean teachers have not imported rosters yet.
  • Top / at-risk students use the average score of every attempt (not the best attempt) — a student in both lists is sitting easy and hard exams.
  • Performance by class / subject respects the class + subject filters at the top; the pass-rate bar uses the baseline you pick.
  • Participation compares attempts in the last 30 days with roster size per class — a class with many students and zero attempts needs a follow-up.
  • Gender + birthdays appear once rosters include the optional Gender / DateOfBirth CSV columns (teacher roster import, Phase 12N).
  • Everything is exportable (JSON for records, CSV for spreadsheets, Print for PDF) — the exports always match exactly what the filters show.
